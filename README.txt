                             AllBinary Platform Tcl

What is it?

This repository contains code generated by the AllBinary Platform for support in Tcl.  
This repo is used to allow developers to skip the Tcl code generation step.

What are some example games with this Tcl code?

https://allbinary.itch.io (The downloads with "-tcl" in the filename are Tcl only builds. Currently that only includes nothing. Also the Tcl builds are not available on Google Play or other stores.)
